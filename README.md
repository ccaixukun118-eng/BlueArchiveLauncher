# Blue Archive Launcher  This folder contains the WPF launcher shell described in the provided development plan.  ## Current implementation  - .NET 8 WPF target with a .NET 6 compatibility target for the current machine. - MVVM shell with Global, CN, and JP server switching. - Server-specific mock dashboard data. - Per-server JSON cache and selected-server persistence. - Cancellation/version guards for rapid server switching. - File logging under `%LOCALAPPDATA%\BlueArchiveLauncher\logs`. - Real MuMu process detection with no fake launch success.  ## Build and run  ```powershell dotnet restore -p:TargetFramework=net6.0-windows dotnet build -c Debug -f net6.0-windows dotnet run -c Debug -f net6.0-windows ```  The next implementation stage adds real GameKee/Kivo sources, SQLite caching, MuMu instance/ADB control, diagnostics, and feature pages.
